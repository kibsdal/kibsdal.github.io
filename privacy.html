Privacy policy

Last updated: 26 October 2026

Jarvis is a personal application used only by its owner, Gustav Kibsdal. It is not available to anyone else.

Data accessed

With the owner's consent, Jarvis accesses the owner's own Google account data (Gmail, Calendar, Drive, Docs, Sheets and Contacts) through Google APIs.

Use and storage

Data is used solely to assist the owner. OAuth tokens and any retrieved data are stored on the owner's own computer. Data is not sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Jarvis's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue at github.com/kibsdal/kibsdal.github.io.
